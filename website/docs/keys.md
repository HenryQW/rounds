---
title: Keys
description: The keys of the session window.
---

| Key | Action |
| --- | --- |
| Type | Filter the list. |
| ↑ ↓ | Move through the rows. |
| ↵ | Open the selected row (or the first row) and close the window. |
| ⌘D | Mark as Done. |
| ⌘S | Star or Unstar. |
| ⌘⌫ | Hide, while the search field is empty. |
| ⌘1 to ⌘5 | Pick All, Last Call, On Tap, Served or Aged. |
| ⌘Z, ⇧⌘Z | Undo and redo Mark as Done and Hide. |
| ⌘, | Open Settings. |
| Esc | Clear the search, then close the window. |

The global shortcut for the window is set in Settings, on the General page.
